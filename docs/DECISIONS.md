# TauriLaunch 决策记录

## 已确认决策

- 平台：第一版只支持 Windows。
- 技术栈：Tauri v2 + React + TypeScript。
- 包管理器：npm。
- 项目结构：保留官方 `create-tauri-app` 默认结构。
- 数据持久化：本地 JSON。
- 数据来源：目录扫描 + 手动添加。
- 扫描时机：启动时扫描一次，托盘菜单 `扫描` 手动刷新。
- 搜索：实时过滤，按配置延迟执行；回车启动第一个匹配项。
- 图标：从 `.lnk` / `.exe` 提取并缓存。
- 启动目标：`.lnk` 使用解析后的目标、参数、工作目录；`.exe` 直接启动。
- 条目管理：第一版支持添加、删除/隐藏、重新扫描；暂不做完整编辑器。
- 主窗口位置：固定在当前显示器可用区域右下角，右边距和下边距来自设置窗口。
- 主窗口生命周期：关闭、失焦、启动应用后销毁主 WebView 窗口。
- 托盘进程：销毁主窗口时保留；只有托盘 `退出` 结束整个程序。

## 当前实现边界

- M1 已实现基础布局、托盘菜单、窗口创建/销毁、主窗口右下角定位、右/下边距读写。
- 扫描、图标提取、启动统计在 M2/M3/M4 实现。
- WebView2 Runtime 已存在，不需要额外安装。
- WebView2 是系统共享组件；需求口径是释放 TauriLaunch 主 WebView 窗口，不要求杀掉系统级 WebView2 Runtime。
- 主窗口位置设置保存到 `%LOCALAPPDATA%\com.fengqi.taurilaunch\settings.json`。

## 后续改动原则

- 用户提出的产品行为、功能范围、交互规则调整，要同步更新相关文档。
- 只修 bug、不改变产品行为的改动，不需要更新产品计划。
- 文档只保留最终版本，不按日期堆叠事后记录。
- 新功能优先保持小接口和本地实现，不提前引入数据库。
- 跨会话继续开发前先读：
