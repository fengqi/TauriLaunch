# TauriLaunch 决策记录

## 已确认决策

- 平台：第一版只支持 Windows。
- 技术栈：Tauri v2 + React + TypeScript。
- 包管理器：npm。
- 项目结构：保留官方 `create-tauri-app` 默认结构。
- 数据持久化：本地 JSON，不引入数据库。
- 配置文件：`%LOCALAPPDATA%\TauriLaunch\settings.json`。
- 应用列表文件：`%LOCALAPPDATA%\TauriLaunch\apps.json`。
- 数据来源：目录扫描 + 手动添加。
- 目录配置：监听目录保存到 `settings.json` 的 `watchedDirectories`。
- 扫描时机：启动时扫描一次，托盘菜单 `扫描` 和主界面 `扫描` 可手动刷新。
- 扫描范围：递归扫描监听目录中的 `.exe` 和 `.lnk`，并通过 Windows `Get-StartApps` 读取已注册的开始菜单应用。
- `.lnk` 解析：当前使用 Windows WScript Shell COM 读取目标路径、启动参数和工作目录；目标文件不存在时跳过该快捷方式，不写入应用列表，也不提取图标。
- 应用商店 / MSIX 应用：不要求存在监听目录快捷方式；扫描阶段读取 `Get-StartApps` 的 `AppID`，保存为 `shell:AppsFolder\...` 启动目标。
- 扫描执行：`scan_apps`、托盘扫描和启动扫描都只负责启动后台扫描任务，不在调用线程同步执行扫描。前端点击扫描后立即返回，当前列表保持可滚动、可启动应用。
- 扫描状态：后台扫描运行时禁用托盘 `扫描` 菜单项，并向前端发送 `scan-state-changed`，主界面扫描按钮显示转圈状态。
- 扫描结果：后台任务写入 `apps.json`。主窗口可见时通过 `apps-updated` 事件刷新列表；主窗口隐藏或 WebView 已销毁时不主动刷新，下一次打开时读取最新本地数据。
- 防重复扫描：进程内同一时间只运行一个扫描任务；已有扫描运行时再次触发扫描直接忽略。
- 增量扫描：扫描到同一 `source` 的旧条目时，如果启动目标存在、工作目录有效或为空、启动参数可解析、图标缓存路径是当前 `{id}-128.png` 格式且文件存在，则直接复用旧记录，避免重复解析快捷方式和重复提取图标；重建条目时按 `id`、`source`、实际启动目标加启动参数继承旧 metadata。
- 重新处理条件：旧条目启动目标不存在、工作目录失效、启动参数不可解析或图标缓存缺失时，重新解析对应 `.lnk` / `.exe` 或重新读取开始菜单应用。残留快捷方式的目标不存在时跳过；目标恢复后再重新加入。
- 启动统计：扫描刷新时保留已有条目的 `launches`，真实递增在 M3 实现。
- 搜索：实时过滤由 `liveSearchEnabled` 控制，按 `searchDelayMs` 延迟执行；回车启动第一个匹配项由 `enterLaunchEnabled` 控制。英文和路径搜索索引在扫描阶段由后端生成并写入 `apps.json` 的 `searchText`；中文拼音和拼音首字母搜索由 Rust 后端 `ib-pinyin` 在 `search_apps` 命令中执行。前端不再计算拼音。
- 搜索状态：主窗口关闭、失焦隐藏、启动应用、轻量模式销毁窗口前都会清空搜索；搜索框提供显式清空按钮。
- 图标：扫描阶段从 `.lnk` / `.exe` 或应用商店 / MSIX 的 Appx 包清单提取并缓存到 app data 的 `icons` 目录；应用商店 / MSIX 图标会裁掉透明留白再缓存；优先提取较大尺寸图标，前端最多显示 `48x48`，提取失败时显示首字母占位。
- 启动目标：`.lnk` 使用解析后的目标、启动参数、工作目录；应用商店 / MSIX 条目使用 `shell:AppsFolder\...` 通过 ShellExecute `open` 启动；`.exe` 使用保存的路径和启动参数启动。启动成功后递增启动次数；启动失败时保存最后一次错误信息。遇到 Windows 740 “请求的操作需要提升”时，回退到 ShellExecute `runas`，让系统弹 UAC。
- 条目管理：第一版支持添加、右键操作、隐藏、重新扫描；暂不做完整编辑器。删除默认隐藏，隐藏条目保留在 `apps.json`，同一条目重新扫描后仍保持隐藏；设置中启用物理删除后，删除会移除本地记录，后续扫描可重新发现。
- 隐藏条目显示：默认不显示隐藏条目；设置中启用后，隐藏条目显示在列表最后，并使用淡化样式。
- 手动添加：主界面 `添加` 打开系统文件选择框，只允许 `.exe` 和 `.lnk`。选择框打开期间主窗口不因失焦隐藏或销毁。添加已有可见条目时不重复添加；添加隐藏条目时恢复显示，并将 `launches` 清空为 0。
- 条目右键菜单：包含置顶、重置位置、修改名称、打开所在目录、删除。修改名称只改显示名称，不改路径、启动参数和工作目录。
- 主窗口位置：固定在当前显示器可用区域右下角，右边距和下边距来自设置窗口。
- 主窗口外观：主窗口使用无原生标题栏的自定义内容区，标题和关闭按钮只显示一次。
- 任务栏显示：所有窗口都跳过任务栏，只保留托盘图标作为常驻入口。
- 主窗口密度：主窗口默认使用紧凑尺寸和 6 列应用网格，减少留白和卡片间距。
- 主窗口排序：应用列表按启动次数从大到小排列，启动次数相同时按名称排序。
- 主窗口滚动：应用数量超过一屏时只允许纵向滚动并隐藏滚动条，禁止横向滚动条和宽度溢出。
- 主窗口焦点：主窗口创建或重新显示时聚焦搜索框，便于直接输入过滤关键字。
- 悬停信息：应用悬停信息使用窗口级 fixed 浮层，按实际尺寸自动翻转左右和上下方向；浮层不接收鼠标事件。
- 辅助窗口位置：设置和关于窗口创建时通过窗口构建器直接居中，首帧即居中显示。
- 设置窗口外观：保留系统原生标题栏，内容区直接从页签开始，不重复显示 `设置` 标题。
- 设置窗口密度：设置窗口默认约 `500x320`，页签即分组标题，内容区不重复二级标题，统一使用紧凑字体、表单行和按钮。
- 启动行为：开机启动默认到托盘，普通双击启动默认显示主窗口，二者都可在设置中修改。
- 托盘进程：关闭窗口时保留进程；只有托盘 `退出` 结束整个程序。
- 托盘 `轻量模式`：每次启动默认不勾选，不保存到本地 JSON；未勾选时主窗口和设置窗口关闭后隐藏；勾选时关闭后先隐藏，60 秒内重新打开则复用，超过 60 秒仍未重新打开再销毁 WebView；从未勾选切换为勾选时，已隐藏保留的主窗口和设置窗口按同样 60 秒延迟销毁策略释放。
- 主窗口失焦：失焦事件触发后延迟确认仍未聚焦再执行隐藏，避免焦点抖动；轻量模式下隐藏后 60 秒再销毁。

## 当前实现边界

- M1 已实现基础布局、托盘菜单、窗口显示/隐藏/销毁、主窗口右下角定位、辅助窗口创建时居中、右/下边距读写、启动行为设置、托盘 `轻量模式`。
- M2 已实现 `settings.json`、`apps.json`、监听目录读写、启动扫描、托盘扫描、主界面扫描、`.exe` 扫描、`.lnk` 基础解析、前端应用列表读取后端数据。
- M3 已实现真实启动、单击启动、启动后清空搜索和刷新列表、启动参数传递、工作目录、启动次数递增、按启动次数排序、右键条目操作、显示名称修改、打开所在目录、最后一次错误信息、隐藏条目、搜索延迟和回车启动设置。
- M4 已实现图标提取、图标缓存、图标大小设置、开机启动设置、系统目录选择器、空状态和扫描失败提示。
- WebView2 Runtime 已存在，不需要额外安装。
- WebView2 是系统共享组件；需求口径是按 `轻量模式` 隐藏或释放 TauriLaunch 自己的 WebView 窗口，不要求杀掉系统级 WebView2 Runtime。
