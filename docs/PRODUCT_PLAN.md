# TauriLaunch 产品计划

## 产品目标

TauriLaunch 是一个面向 Windows 的软件启动器。它常驻托盘，按需显示主窗口，帮助用户从指定目录和手动添加项中快速搜索、启动应用。

- `docs/design/launcher-main.png`
- `docs/design/settings-dialog.png`
- `docs/design/tray-context-menu.png`

## MVP 范围

第一版目标是做成可用启动器，不只做静态界面。

- 扫描目录中的 `.lnk` 和 `.exe`
- 手动添加应用
- 展示应用图标、名称、路径、启动次数
- 搜索并启动应用
- 保存设置和启动统计
- 常驻托盘，支持扫描、设置、退出
- 主窗口关闭、失焦、启动应用后释放主 WebView 窗口

暂不做：

- 分类管理
- 拖拽排序
- 完整条目编辑器
- 云同步
- 多用户配置
- 非 Windows 平台支持

## 功能列表

### 主界面

- 顶部显示 `应用列表`、搜索框、`添加`、`关闭`。
- 中间以网格展示应用。
- 每个应用显示图标和名称。
- 鼠标悬停显示启动次数和路径。
- 输入搜索关键字后按配置延迟过滤。
- 回车启动第一个匹配项。
- 点击 `关闭` 时销毁主窗口，但保留托盘进程。

### 设置窗口

- `目录监听`
  - 展示监听目录列表。
  - 支持浏览、添加、删除目录。
- `图标设置`
  - 支持配置图标大小，例如 `32x32`。
- `界面设置`
  - 窗口距屏幕右边距离。
  - 窗口距屏幕下边距离。
  - 开启实时搜索功能。
  - 搜索执行延迟，单位毫秒。
  - 搜索后回车打开首个。
- `其他设置`
  - 自动添加桌面快捷方式。
  - 开机启动。
- `信息`
  - 展示版本和基础说明。

### 托盘菜单

- `关于`
- `扫描`
- `设置`
- `退出`

`退出` 是唯一会结束整个程序的入口。

### 后端能力

- 扫描目录中的 `.lnk` 和 `.exe`。
- 解析快捷方式目标、参数、工作目录、图标。
- 提取并缓存应用图标。
- 使用本地 JSON 保存配置、条目、隐藏状态、启动次数。
- 启动外部应用，并在启动后销毁主窗口。

## 窗口生命周期

用户感知上是隐藏主窗口；实现上使用销毁主 WebView 窗口。

- 点击主窗口关闭按钮：销毁主窗口，保留托盘进程。
- 主窗口失焦：销毁主窗口，保留托盘进程。
- 成功启动外部应用后：先保存统计，再销毁主窗口。
- 点击托盘图标或托盘菜单需要主界面时：如果主窗口不存在，则重新创建。
- 点击托盘 `退出`：退出整个 TauriLaunch 进程。

说明：WebView2 Runtime 是系统共享组件，不要求系统级 WebView2 进程全部消失。要求是 TauriLaunch 不长期保留隐藏的主 WebView 窗口。

## 验收标准

- 启动后能显示主窗口。
- 托盘菜单包含 `关于`、`扫描`、`设置`、`退出`。
- 主窗口关闭后托盘仍保留。
- 主窗口失焦后被销毁。
- 托盘可重新打开主窗口。
- `退出` 后程序结束。
- 后续实现扫描后，目录和统计能跨重启保存。

## 追加决策：主窗口位置

- 主窗口固定显示在当前显示器可用区域的右下角。
- 右边距由设置项 `窗口位置与屏幕右边距离` 控制。
- 下边距由设置项 `窗口位置与屏幕下边距离` 控制。
- 每次创建或重新显示主窗口时，都重新读取本地设置并计算位置。
- 当前实现已经支持保存这两个设置项到本地 `settings.json`。
