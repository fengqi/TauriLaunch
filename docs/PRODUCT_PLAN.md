# TauriLaunch 产品计划

## 产品目标

TauriLaunch 是一个面向 Windows 的软件启动器。它常驻系统托盘，按配置决定是否显示主窗口，用于从监听目录和手动添加项中快速搜索、启动应用。

## MVP 范围

- 扫描监听目录中的 `.lnk` 和 `.exe`。
- 手动添加应用。
- 展示应用图标、名称、路径、启动参数、启动次数。
- 搜索并启动应用。
- 使用本地 JSON 保存配置、应用列表、隐藏状态和启动统计。
- 常驻托盘，菜单包含 `关于`、`扫描`、`设置`、`轻量模式`、`退出`。
- 主窗口固定在当前显示器可用区域右下角，右边距和下边距来自设置。
- 主窗口使用无原生标题栏的自定义内容区，标题和关闭按钮只显示一次。
- 所有窗口都不显示任务栏图标，只保留系统托盘入口。
- 设置窗口和关于窗口创建时通过窗口构建器直接居中。
- 开机启动和双击启动可分别配置为启动到托盘或显示主窗口。

暂不做分类管理、拖拽排序、完整条目编辑器、云同步、多用户配置和非 Windows 平台支持。

## 功能列表

### 主界面

- 顶部显示 `应用列表`、搜索框、`扫描`、`添加`、`关闭`。
- 主窗口创建或重新显示时，自动把输入焦点定位到搜索框。
- 应用以 6 列紧凑网格展示。
- 应用列表按启动次数从大到小排列，启动次数相同时按名称排序。
- 应用数量超过一屏时只允许纵向滚动，隐藏滚动条，禁止横向滚动和宽度溢出。
- 每个应用显示图标占位和名称。
- 鼠标悬停显示启动次数、路径和启动参数。
- 启动参数为空时不显示该行。
- 悬停信息使用窗口级浮层，按条目位置和浮层尺寸自动选择右侧/左侧和下方/上方，避免超出窗口或被滚动区域裁剪。
- 悬停信息不拦截鼠标事件，避免盖住其他条目后悬停状态卡住。
- 输入搜索关键字后按配置延迟过滤。
- 搜索框提供清空按钮；点击关闭、主窗口失焦隐藏、启动外部应用、切换轻量模式销毁窗口前都清空搜索状态。
- 搜索支持英文任意片段、英文单词首字母、中文拼音和中文拼音首字母。例如 `ActivityWatch` 可用 `act`、`wat`、`aw` 搜索，`微信` 可用 `wx`、`wei`、`xi` 搜索，`网易云音乐` 可用 `wyyyy`、`wang` 搜索。英文索引由扫描阶段生成并写入 `apps.json`，中文拼音匹配由 Rust 后端 `ib-pinyin` 执行。
- 回车启动第一个匹配项。
- 单击应用条目启动应用。
- 应用启动成功后清空搜索状态，并刷新应用列表。
- 右键应用条目显示操作菜单，并屏蔽系统默认右键菜单。
- 右键菜单包含 `置顶`、`重置位置`、`修改名称`、`打开所在目录`、`删除`。
- `置顶` 将当前应用启动次数设置为当前最大启动次数加 2。
- `重置位置` 将当前应用启动次数设置为 0。
- `修改名称` 在应用名称原位置切换为输入框；焦点脱离取消修改，回车保存修改。只修改显示名称，不修改路径、启动参数和工作目录。
- `打开所在目录` 打开当前应用 exe 文件所在目录。
- `删除` 按隐藏处理，不从 `apps.json` 物理删除。
- 点击 `添加` 打开系统文件选择框，可选择 `.exe` 或 `.lnk`；文件选择框打开期间主窗口不能因失焦隐藏或销毁。
- 添加已有可见条目时不重复添加；添加曾经删除/隐藏的同一条目时恢复显示，并将启动次数清空为 0。
- 点击 `关闭`、主窗口失焦、启动外部应用后，按托盘 `轻量模式` 状态隐藏或销毁主窗口。

### 设置窗口

- 使用系统原生标题栏显示 `设置`，内容区不重复显示标题。
- 默认尺寸约 `500x320`，采用紧凑页签和表单布局。
- 页签即分组标题，内容区不再重复显示二级标题。
- `目录监听`：显示监听目录列表，支持输入路径、添加、删除目录。`浏览` 按钮保留，后续接系统目录选择器。
- `图标设置`：配置图标大小，可选 `32x32`、`38x38`、`48x48`。
- `界面设置`：配置主窗口右边距、下边距、实时搜索、搜索延迟、回车打开首个。
- `其他设置`：配置自动添加桌面快捷方式、开机启动、开机启动行为、双击启动行为。
- `信息`：显示版本和基础说明。
- 点击 `确定` 保存设置到本地配置文件，并按 `轻量模式` 状态隐藏或销毁设置窗口。
- 点击 `取消` 不保存修改，并按 `轻量模式` 状态隐藏或销毁设置窗口。

### 托盘菜单

- `关于`
- `扫描`
- `设置`
- `轻量模式`
- `退出`

`轻量模式` 位于 `设置` 后、`退出` 前。每次启动默认不勾选，不保存到本地 JSON。

- 未勾选：主窗口和设置窗口关闭后隐藏，便于下次快速显示。
- 勾选：主窗口和设置窗口关闭后销毁 WebView，释放窗口资源。
- 从未勾选切换到勾选时，立即销毁已隐藏保留的主窗口和设置窗口 WebView。

`退出` 是唯一会结束整个程序的入口。

### 后端能力

- 读取和写入 `%LOCALAPPDATA%\com.fengqi.taurilaunch\settings.json`。
- 读取和写入 `%LOCALAPPDATA%\com.fengqi.taurilaunch\apps.json`。
- 启动时扫描配置里的监听目录。
- 托盘菜单 `扫描` 和主界面 `扫描` 会启动后台扫描任务并立即返回，不阻塞当前主窗口滚动和启动操作。
- 扫描完成后写入最新应用列表；主窗口可见时刷新当前列表，隐藏或销毁时不主动刷新，下一次打开时读取最新本地数据。
- 递归扫描监听目录中的 `.exe` 和 `.lnk`。
- `.exe` 条目使用文件路径、文件名和父目录生成基础应用信息。
- `.lnk` 条目通过 Windows WScript Shell 解析目标路径、启动参数和工作目录；目标文件不存在时不生成应用条目，也不提取图标。
- 扫描结果写入 `apps.json`，并在主窗口可见时发送 `apps-updated` 事件刷新列表。
- 同一时间只运行一个扫描任务；已有扫描运行时再次触发扫描不会启动第二个扫描。
- 扫描阶段生成 `initials` 和 `searchText`，用于图标占位和英文/路径搜索匹配。
- `search_apps` 后端命令负责搜索过滤：普通文本匹配 `searchText`，中文拼音匹配应用名称。
- `launch_app` 后端命令负责按条目 id 启动真实应用，传递启动参数和工作目录。
- 普通启动失败且 Windows 返回“请求的操作需要提升”时，后端改用系统 Shell 以 `runas` 方式启动，由 Windows 弹出 UAC 提示；用户取消 UAC 时按启动失败处理。
- `add_app` 后端命令负责从用户选择的 `.exe` / `.lnk` 创建或恢复应用条目。
- 启动成功后递增启动次数，启动失败时保存最后一次错误信息。
- `get_apps`、`search_apps` 和 `launch_app` 返回的应用列表按启动次数从大到小排列，启动次数相同时按名称排序；`scan_apps` 只负责启动后台扫描。
- 扫描时保留已有条目的启动次数、显示名称、隐藏状态和最后一次错误信息。
- 扫描采用增量处理：同一来源的旧条目如果启动目标存在、工作目录有效或为空、启动参数可解析、图标缓存路径是当前 `{id}-256.png` 格式且文件存在，则直接复用旧记录，不重新解析快捷方式或提取图标。
- 旧条目启动目标不存在、图标缓存缺失、启动参数不可解析或工作目录失效时，重新解析对应 `.lnk` / `.exe`；`.lnk` 目标仍不存在时跳过该条目，目标恢复后再重新加入。
- 删除条目按隐藏处理，隐藏条目保留在 `apps.json`，重新扫描不会重新显示同一条目。
- 手动添加隐藏条目时会恢复显示并清空启动次数。
- 图标提取在扫描阶段执行，成功后缓存到 app data；图标缓存缺失的旧条目会在后续扫描中重新提取。

## 窗口生命周期

- 开机启动通过 `--startup` 或 `--autostart` 参数识别，默认只启动到托盘，不创建主 WebView 窗口。
- 普通双击启动默认显示主窗口；如果设置为启动到托盘，则只创建托盘进程。
- 主窗口每次创建或重新显示时，读取设置并定位到当前显示器可用区域右下角。
- 设置窗口和关于窗口创建时直接居中显示，不能先在左上角显示后再移动。
- 主窗口和设置窗口关闭策略由托盘 `轻量模式` 决定，状态只在当前进程内生效。
- 主窗口失焦后需要延迟确认窗口仍未聚焦，再隐藏或销毁，避免焦点事件短暂抖动。
- 关于窗口关闭时直接销毁。
- 主窗口、设置窗口、关于窗口在创建和重新显示时都设置为不显示任务栏图标。
- 点击托盘图标或托盘菜单需要主窗口/设置窗口时：如果窗口存在则重新显示；如果窗口不存在则重新创建。
- 点击托盘 `退出`：退出整个 TauriLaunch 进程。

说明：WebView2 Runtime 是系统共享组件，不要求系统级 WebView2 进程全部消失。TauriLaunch 是否长期保留隐藏的主窗口和设置窗口 WebView，由当前进程内的 `轻量模式` 决定。

## 验收标准

- 启动后能按设置决定是否显示主窗口。
- 主窗口显示在当前显示器可用区域右下角。
- 设置窗口保存右边距、下边距后，下一次打开主窗口按新位置显示。
- 开机启动默认不显示主窗口，只保留托盘。
- 普通双击启动默认显示主窗口。
- 设置窗口可维护监听目录，并保存到 `settings.json`。
- 设置窗口 `浏览` 按钮使用系统目录选择器。
- 启动时会扫描监听目录，并写入 `apps.json`。
- 托盘和主界面的 `扫描` 都会启动后台扫描并更新本地应用列表；扫描期间主窗口列表保持可滚动、可启动应用。主窗口可见时在扫描完成后刷新当前列表，隐藏或销毁时等下次打开读取最新数据。
- `.lnk` 条目能解析出目标路径、启动参数和工作目录。
- 主界面 `添加` 可选择 `.exe` / `.lnk`，添加期间主窗口保持显示；重复添加可见条目不生成重复项，添加隐藏条目会恢复显示并清空启动次数。
- `.exe` / `.lnk` 条目有图标缓存时优先显示真实图标，没有图标时显示首字母占位。
- 图标大小设置保存后影响应用网格图标尺寸。
- 主界面不再依赖硬编码测试应用数据。
- 托盘菜单包含 `关于`、`扫描`、`设置`、`轻量模式`、`退出`。
- `轻量模式` 每次启动默认不勾选，勾选状态不写入 JSON。
- 未勾选 `轻量模式` 时，主窗口和设置窗口关闭后隐藏。
- 勾选 `轻量模式` 时，主窗口和设置窗口关闭后销毁 WebView。
- 托盘可重新显示或创建主窗口。
- `退出` 后程序结束。
