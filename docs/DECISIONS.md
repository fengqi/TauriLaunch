# TauriLaunch 决策记录

## 已确认决策

- 平台：第一版只支持 Windows。
- 技术栈：Tauri v2 + React + TypeScript。
- 包管理器：npm。
- 项目结构：保留官方 `create-tauri-app` 默认结构。
- 数据持久化：本地 JSON。
- 数据来源：目录扫描 + 手动添加。
- 扫描时机：启动时扫描一次，托盘菜单 `扫描` 手动刷新。
- 搜索：实时过滤，按配置延迟执行；回车启动第一个匹配项。
- 图标：从 `.lnk` / `.exe` 提取并缓存。
- 启动目标：`.lnk` 使用解析后的目标、启动参数、工作目录；`.exe` 使用保存的路径和启动参数启动。
- 条目管理：第一版支持添加、删除/隐藏、重新扫描；暂不做完整编辑器。
- 主窗口位置：固定在当前显示器可用区域右下角，右边距和下边距来自设置窗口。
- 主窗口外观：主窗口使用无原生标题栏的自定义内容区，标题和关闭按钮只显示一次。
- 任务栏显示：所有窗口都跳过任务栏，只保留托盘图标作为常驻入口。
- 主窗口密度：主窗口默认使用紧凑尺寸和 6 列应用网格，减少留白和卡片间距。
- 主窗口滚动：应用数量超过一屏时只允许纵向滚动并隐藏滚动条，禁止横向滚动条和宽度溢出。
- 悬停信息：应用悬停信息使用窗口级 fixed 浮层，按实际尺寸自动翻转左右和上下方向；浮层不接收鼠标事件，避免提示层盖住其他条目后悬停状态卡住。
- 辅助窗口位置：设置和关于窗口创建时通过窗口构建器直接居中，首帧即居中显示。
- 设置窗口外观：保留系统原生标题栏，内容区直接从页签开始，不重复显示 `设置` 标题。
- 设置窗口密度：设置窗口默认约 `500x320`，页签即分组标题，内容区不重复二级标题，统一使用紧凑字体、表单行和按钮。
- 启动行为：开机启动默认到托盘，普通双击启动默认显示主窗口，二者都可在设置中修改。
- 托盘进程：关闭窗口时保留；只有托盘 `退出` 结束整个程序。
- 托盘 `轻量模式`：每次启动默认不勾选，不保存到本地 JSON；未勾选时主窗口和设置窗口关闭后隐藏；勾选时主窗口和设置窗口关闭后销毁 WebView；从未勾选切换为勾选时立即销毁已隐藏保留的主窗口和设置窗口 WebView。
- 主窗口失焦：失焦事件触发后延迟确认仍未聚焦再执行隐藏或销毁，避免焦点抖动，同时覆盖快速点击外部导致的漏关。

## 当前实现边界

- M1 已实现基础布局、托盘菜单、窗口显示/隐藏/销毁、主窗口右下角定位、辅助窗口创建时居中、右/下边距读写、启动行为设置、托盘 `轻量模式`。
- 扫描、图标提取、真实启动、启动统计在 M2/M3/M4 实现。
- WebView2 Runtime 已存在，不需要额外安装。
- WebView2 是系统共享组件；需求口径是按 `轻量模式` 隐藏或释放 TauriLaunch 自己的 WebView 窗口，不要求杀掉系统级 WebView2 Runtime。
- 主窗口位置设置保存到 `%LOCALAPPDATA%\com.fengqi.taurilaunch\settings.json`。
- 开机启动行为和双击启动行为也保存到同一个 `settings.json`。

## 后续改动原则

- 用户提出的产品行为、功能范围、交互规则调整，要同步更新相关文档。
- 只修 bug、不改变产品行为的改动，不需要更新产品计划。
- 文档只保留最终版本，不按日期堆叠事后记录。
- 新功能优先保持小接口和本地实现，不提前引入数据库。
- 跨会话继续开发前先读：
  - `docs/PRODUCT_PLAN.md`
  - `docs/DECISIONS.md`
  - `docs/DEV_NOTES.md`
